# Vibepollo 1.15.31 Release Design

## Objective

Ship a traceable Vibepollo 1.15.31 patch that closes the embedded Web UI dependency alerts, repairs the repository's static-analysis gates, preserves the proven streaming/display/secure-input behavior, and upgrades the installed Windows host without changing Tim's configuration.

## Observed starting point

- Release 1.15.30 is installed and public at commit `b4d24217fcd6e5f85bbe302fea9f28de3086cdcd`.
- Commit `dc2abcd9` changes only the Web UI lockfile and resolves the current `nanoid`, `js-yaml`, `fast-uri`, and `brace-expansion` advisories. `npm audit` reports zero vulnerabilities across 437 packages.
- Windows Git checks text files out as CRLF while the Web UI Prettier policy requires LF. This produces tens of thousands of line-ending diagnostics that obscure real lint findings.
- `vue-tsc` reports 125 diagnostics across 23 files. These diagnostics predate the lockfile update and are concentrated in the WebRTC client, WebRTC view, and application editor.
- The frontend Vitest configuration and tests exist, but the required test dependencies and package script are absent and one old test references removed components.
- The protected native baseline is 400 tests: 358 pass, 9 skip, and 33 known failures in legacy config-consistency, fork-name, and display-device expectations. Those failures are accepted only when the population and failure identities remain unchanged.

## Architecture

Keep the patch layered and attributable. First establish one LF checkout contract and restore a runnable Web UI test harness. Then repair TypeScript and lint findings in bounded feature clusters without relaxing compiler or lint rules. Treat native behavior as a protected surface: no display, secure-input, audio, service, configuration, bitrate, GPU-priority, or Vibelight changes are authorized unless a new red test and runtime evidence prove an actual regression.

The shipping artifact is built only after the final release commit is created. CMake, Inno Setup, binary metadata, the Git tag, the GitHub asset, and the installed runtime must all identify 1.15.31 and the same final commit.

## Non-goals

- No Vibelight source, Flatpak manifest, Deck launcher, bitrate, network, HDR, game, or GPU-tuning change.
- No dependency major-version migration or framework modernization.
- No blanket rewrite of the 33 protected native expectations.
- No change to `sunshine.conf`, `apps.json`, pairing data, private game entries, or device-specific infrastructure.
- No service force-kill or direct replacement of a running binary.

## Regression invariants

1. The full native suite is rerun for this new commit; the prior exact-commit exception does not carry forward.
2. The protected baseline remains 400 total / 358 pass / 9 skip / 33 failures unless a separately reviewed red test proves a real defect and the new total is explained.
3. Focused display restore/topology and secure-input tests pass.
4. C1 teardown requires both physical monitors to return unaided and a helper terminal receipt containing `Restore confirmed` or a coherent database-fallback confirmation. `REVERT accepted` is dispatch only.
5. Deck clock-to-PIN input remains a human-observed gate because the host logs do not instrument the Winlogon transition.
6. `VibepollService`, not a Scheduled Task, remains the LocalSystem startup owner.
7. The installer upgrade preserves `sunshine.conf` and `apps.json` byte-for-byte.
8. Installed main, helper, and service hashes match the release build; ports 47989, 47990, and 48010 listen; HTTP and HTTPS server-info probes pass; H.264, HEVC, and AV1 initialize.
9. Release identity is the tuple: version 1.15.31, final embedded source commit, and installer digest. A correct visible version with a parent commit is a release failure.

## Acceptance

- `npm audit`, Prettier, ESLint, `vue-tsc`, Vitest, and the production Vite build exit zero.
- The dependency alert fixes remain present and no new advisory is introduced.
- The native focused gates pass and the complete suite reproduces or improves the protected baseline without unexplained changes.
- An independent reviewer finds no critical or important defect in the complete branch diff.
- The privacy scan finds no personal infrastructure, device identifiers, local user paths, credentials, or private app inventory.
- Short C1 and Deck hardware gates pass on the final installed candidate.
- The pull request merges, `v1.15.31` points to the merged final commit, the published installer hash matches the locally verified artifact, and the local checkout plus installed host align with that commit.
